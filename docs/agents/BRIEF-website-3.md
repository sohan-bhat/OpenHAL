# Brief: website round 4, the owner's fixes

Read docs/agents/COMMON.md first, then docs/DESIGN.md and website/ with its tests. Load the skills frontend-design:frontend-design, design-taste-frontend, web-design-guidelines and playwright-cli before UI work. The site is live at https://sohan-bhat.github.io/OpenHAL/ and redeploys from main through .github/workflows/pages.yml, which builds for the root and then runs website/scripts/rebase.mjs to serve it under /OpenHAL/.

## The owner's list

1. **Small quirks go.** Remove small decorative bits that add noise. The owner's two examples were screenshots kept in the orchestrator's scratch folder. One is a status chip with a dot and the uppercase word TESTED. The other is the uppercase micro labels MESSAGE TRACE and RECORDED WITH OPENHAL DEMO above the home page trace. Find every other element of the same kind on every page (uppercase eyebrow labels, little dot chips, corner tags) and remove it, unless it carries meaning nothing else on the page carries.
2. **Message trace narration as comments.** The narration lines ("tank is empty", "tank refilled") render as comments, prefixed with `#`, muted and italic, visually apart from errors and results. Same in the README's text trace. That trace is generated by openhal/demo/trace.py from docs/demo/scenario.yaml and written into README.md and docs/QUICKSTART.md by `uv run python -m openhal.demo.readme`, and tests check it. Change the generator, regenerate, and keep every trace on the site, in the README and in the Inspector's message log consistent.
3. **Promote the Playground.** Add it to the top navigation, and put a "Try it in your browser" link under the home page message trace.
4. **Diagram chips.** Add a small label above the chips, "Click a step", and make the link between the active chip and the highlighted node in the diagram clear.
5. **One page container.** Drivers and Device Library use the same page container and left margin as Overview and Specification.
6. **No horizontal scrolling at 1280 px.** Wrap long lines in the Playground editor and in the SDK code blocks, or widen them, so nothing scrolls sideways at 1280 px. Fix the truncated "As" dropdown label in the Playground ("Agent, control_medium to..." is cut off).
7. **Search.** A site search in the header like the owner's reference. It is a rounded field with a blue magnifying-glass icon on the left, "Search..." in muted text and a bordered ⌘K key badge on the right (Ctrl K off macOS). Pressing ⌘K or Ctrl K or clicking it opens a search dialog over the page, styled in the protocol theme, keyboard navigable and closed by Escape. Use Pagefind (MIT, static, built from dist after `astro build`) or something equally small and static. It must work on the live site under /OpenHAL/, so add the index step to .github/workflows/pages.yml and make sure the rebase step leaves every search URL correct. Check it by serving a rebased build locally under /OpenHAL/ and searching for "LIMIT_EXCEEDED" and "plant waterer". On phones the field becomes an icon button that opens the same dialog.
8. **Verify.** Playwright screenshots of every page at 390, 768 and 1440 px, in light and dark, saved in your scratch folder. Look at them, fix what's off and screenshot again. Lighthouse and axe stay where docs/verification/ui.md records them.
