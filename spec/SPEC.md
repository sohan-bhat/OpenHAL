# OpenHAL device file specification

The device file format is now part of the dated OpenHAL specification. The normative text is [spec/2026-10-24/device-files.md](2026-10-24/device-files.md).

Section numbers are unchanged, so a reference such as "spec section 12" still points to the same rules. The JSON Schema stays at [spec/schema/device-file.schema.json](schema/device-file.schema.json).

The whole specification starts at [spec/2026-10-24/index.md](2026-10-24/index.md). `spec/versions.json` names the latest version.
