# Shared design assets

`tokens.css` holds the colors, type, spacing, syntax theme and motion tokens of the protocol theme in docs/DESIGN.md. The website, the Inspector and the README image tools all use it. Change docs/DESIGN.md first, then this file.

`fonts/` holds the two faces as variable WOFF2 files, subset to Latin, with their SIL Open Font License texts. They come from the fontsource packages, version 5.3.0.

| Face | Files | License |
|---|---|---|
| Atkinson Hyperlegible Next | atkinson-hyperlegible-next-latin-wght-normal.woff2 and the italic | OFL-1.1 |
| Atkinson Hyperlegible Mono | atkinson-hyperlegible-mono-latin-wght-normal.woff2 and the italic | OFL-1.1 |
