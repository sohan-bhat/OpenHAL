# Shared design assets

`tokens.css` holds the colors, type, spacing, grid, limit line and motion tokens from docs/DESIGN.md. The dashboard (`dashboard/`) and the website (`website/`) both import it. Change docs/DESIGN.md first, then this file.

`fonts/` holds the three faces as variable WOFF2 files, subset to Latin, with their SIL Open Font License texts. They come from the fontsource packages, version 5.3.0.

| Face | File | License |
|---|---|---|
| Sofia Sans Condensed | sofia-sans-condensed-latin-wght-normal.woff2 | OFL-1.1 |
| Atkinson Hyperlegible Next | atkinson-hyperlegible-next-latin-wght-normal.woff2 and the italic | OFL-1.1 |
| Martian Mono | martian-mono-latin-wght-normal.woff2 | OFL-1.1 |
